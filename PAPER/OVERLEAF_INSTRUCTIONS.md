# Overleaf Upload Instructions

## Quick upload (recommended)
1. Go to https://www.overleaf.com/project/6a708e0eaeae244617d525cc
2. Click "Upload" → select `paper_overleaf.zip`
3. Overleaf will extract and compile automatically

## Manual upload
Upload these files maintaining the directory structure:
- `main.tex` (root)
- `sections/*.tex` (35 files)
- `bib/references.bib`
- `prompts.tex`

## Compilation
Overleaf will auto-detect pdflatex. Set compiler to pdfLaTeX if needed.
The paper compiles with 0 errors, 0 warnings on TeX Live 2022.

## Pre-compiled PDF
`paper_compiled.pdf` contains the locally compiled output (38 pages)
for reference while Overleaf compiles.
